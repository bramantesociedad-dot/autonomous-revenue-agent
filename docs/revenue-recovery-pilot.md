# 30-Day Revenue Recovery Pilot

Recover revenue you already paid to acquire.

For med spas, aesthetic clinics and dental practices with missed enquiries, dormant leads, no-shows or lapsed patients.

## Outcome

We work inside the existing CRM / booking stack to:

- map missed and dormant revenue opportunities;
- segment the backlog by likely value and intent;
- build reactivation and follow-up workflows;
- track booked appointments and attributable recovered revenue;
- deliver a 30-day results report.

No new ad spend is required.

## Pilot

**USD 2,500 for one location / 30 days.**

The pilot fee is credited toward a longer rollout if the pilot performs.

Before implementation, we quantify the recoverable pipeline. If the economics are weak, we stop before deployment rather than force the project.

## Agency / consultant partners

The pilot can run white-label behind an existing marketing relationship. The partner keeps the client relationship and may package or mark up the service.

## Backlog value model

A simple scenario model is:

`dormant contacts × reachable rate × booking rate × show rate × average collected revenue per completed appointment`

Example only: 1,000 dormant contacts × 30% reachable × 8% booking × 70% show × USD 800 average collected revenue = **USD 13,440 scenario value**.

This is a model, not a guarantee. A real pilot uses the client’s actual CRM, call and booking data.
