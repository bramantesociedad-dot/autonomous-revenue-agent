## Executive summary

The highest-value opportunity this week is not a blanket room-rate cut. The stronger move is to make the direct-booking offer easier to compare with OTAs while packaging a modest-value perk that protects ADR.

## Revenue opportunities

### 1. Direct-booking value stack

Put the direct-booking advantage immediately beside the primary booking CTA. Example structure: best available direct rate + flexible modification + late checkout subject to availability. The objective is to give a visitor a reason to book now without training them to wait for discounts.

### 2. Three-night package test

Instead of cutting every night's rate, test a three-night package with a low-cost perceived-value inclusion. Track package conversion, ADR, length of stay and gross contribution against the standard offer.

### 3. Homepage CTA test

Replace vague language such as “Discover” with a booking-intent CTA such as “Check dates & rates.” Measure booking-engine starts per 100 homepage sessions.

### 4. Destination-intent acquisition

Create pages for specific high-intent searches such as romantic weekend, three-day itinerary, local food weekend or event-weekend accommodation. Each page should connect the search intent to a relevant package and booking CTA.

## 7-day action plan

1. Add a visible direct-booking value proposition beside the primary CTA.
2. Launch one three-night package without changing the base public rate.
3. Run one CTA wording test.
4. Publish one destination-intent landing page.
5. Record baseline booking-engine starts, conversion rate, ADR and length of stay before evaluating the tests.
